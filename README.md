## ✨ Features Implemented
This website includes all 11 required features[cite: 1, 2, 3, 4]:
1. **Home Section:** Displays profile photo, introduction, welcome message, and quick navigation buttons[cite: 2].
2. **About Me Section:** Shares personal background, area of interest (AIML & Web Development), hobbies, and career goals[cite: 2].
3. **Education Section:** Lists academic details in a clean card layout[cite: 2].
4. **Skills Section:** Visualizes core, technical, and non-technical skills using percentage progress bars[cite: 2].
5. **Projects Section:** Highlights completed projects—including the **AI Medicine Reminder Software** built during the college internal hackathon—with interactive project detail popups[cite: 3].
6. **Hobbies & Interests Section:** Displays personal interests with icons and short descriptions[cite: 3].
7. **Achievements & Milestones Section:** Showcases hackathon participation and first-year academic milestones[cite: 3].
8. **Contact Section:** Includes email (`abc@gmail.com`), social links (GitHub & LinkedIn), and a JavaScript-validated contact form[cite: 3].
9. **Dark Mode & Light Mode:** Theme-switching button powered by JavaScript and CSS variables[cite: 3].
10. **Interactive Navigation:** Sticky navigation bar with smooth scrolling and active section highlighting.
11. **Responsive Design:** Adapts cleanly across desktop, tablet, and mobile screen sizes.

## 🛠️ Technologies Used
* **HTML5** – Webpage structure and semantic sections[cite: 4]
* **CSS3** – Styling, Flexbox/Grid layouts, Dark/Light theme variables, and media queries[cite: 4]
* **JavaScript** – Theme toggling, mobile menu, active scroll tracking, and contact form validation[cite: 4]
